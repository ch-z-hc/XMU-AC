# XMU-AC

厦门大学畅课（Tronclass）自动签到工具。保持程序运行，它会持续检查课程点名，在终端显示等待、签到结果和点名结束状态。

## 功能

- **数字签到**：自动获取签到码并提交。
- **GPS 签到**：支持自动处理，是否可用取决于本次点名提供的定位信息。
- **二维码签到**：尝试自动取码，也支持手动粘贴扫码内容。
- **多门课同时检查**：一门课还在等待时，其他课程照常处理。
- **登录与结果确认**：保存登录会话供下次使用，提交后检查本人是否已签到。

默认等班级已签到比例严格超过 30% 后再提交；比例一直未达标就等到点名结束，不补签。名单无法可靠读取时会跳过比例限制。具体规则见[使用指南](docs/guide.md)。

## 开始使用

按[安装与账号配置](docs/guide.md#使用)启动程序，首次运行时输入账号，之后保持终端开启即可。

二维码自动取码受账号权限限制，取不到时使用[手动二维码入口](docs/guide.md#二维码签到)。
