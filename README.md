# XMU-AC

厦门大学畅课（Tronclass）自动签到工具。运行后持续检查课程点名，支持数字、GPS 和二维码签到，并在终端显示等待、签到和结束状态。

## 功能

- 自动读取数字签到码并提交。
- GPS 签到根据接口返回的距离计算候选坐标。
- 二维码签到尝试自动取码；也可粘贴扫码得到的内容。
- 默认等待班级已签到比例超过 30% 后再提交。
- 保存登录会话，重启时尝试复用；提交后检查本人签到状态。

## 使用

```sh
git clone https://github.com/ch-z-hc/XMU-AC.git
cd XMU-AC
pip install -r requirements.txt
python auto_checkin.py
```

首次使用按提示输入学号和密码。也可以通过 `STUDENT_ID`、`PASSWORD` 环境变量提供账号。

运行期间保持程序开启，终端会显示各课程的处理状态。

## 签到规则

默认只有已签到比例**严格超过 30%** 才提交，恰好 30% 时仍等待。如果直到点名结束都没有达到比例，本次不会签到。名单接口异常、人数无法取得或判据不可信时，会跳过这一限制。

GPS 定位依赖接口返回的距离信息；缺少距离信息时无法计算候选坐标。具体结果以本人的签到状态为准。

二维码自动取码取决于学生账号的接口权限；取不到时，可运行 `python auto_checkin.py --qr`，登录后粘贴最新扫码内容。二维码载荷有效期短，过期需重新扫码。
