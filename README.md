# XMU-AC

厦门大学畅课（Tronclass）自动签到工具，支持数字、GPS 和二维码签到。

## 功能

- 持续检查各门课程的点名状态。
- 自动获取数字签到码并提交。
- 支持 GPS 签到，依赖点名返回的定位信息。
- 二维码支持自动取码和手动粘贴扫码内容；自动取码受账号权限限制。
- 保存登录会话，提交后确认本人签到结果。
- 在终端显示等待、签到结果和点名结束状态。

自动签到默认等待班级已签到比例严格超过 30% 后提交；未达标则等到点名结束。名单无法可靠读取时跳过比例限制。
